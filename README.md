# NotePlayer - ESP32 音符播放器

## 项目简介

NotePlayer 是一个基于 ESP32 开发的简易音符播放器。它通过读取电位器的模拟值，映射为 7 个不同的音符（C4 ~ B4），驱动无源蜂鸣器发声，并在一位共阳极数码管上同步显示当前音符编号（1-7）。
---

## 功能特点

-  **7 级音调调节**：旋转电位器可平滑切换 C4、D4、E4、F4、G4、A4、B4 七个音符
-  **数码管实时显示**：采用 74HC595 串行驱动共阳极数码管，显示当前音符编号（1-7）
-  **PWM 音频输出**：使用 ESP32 LEDC 硬件 PWM 驱动无源蜂鸣器，音质清晰
-  **串口调试支持**：通过 Serial 输出当前音符编号，便于调试和监控
-  **低延迟响应**：50ms 循环周期，电位器调节几乎无延迟

## 硬件清单

| 组件 | 型号/规格 | 数量 | 备注 |
|------|-----------|------|------|
| 开发板 | ESP32 Dev Module | 1 | 任意 ESP32 开发板均可 |
| 蜂鸣器 | 无源蜂鸣器（5V） | 1 | 必须是无源，有源蜂鸣器无法播放 PWM 音频 |
| 数码管 | 共阳极数码管 | 1 | 共阴极需修改字体表 |
| 74HC595 | 移位寄存器芯片 | 1 | 用于驱动数码管，节省 IO 口 |

---

## 引脚连接表

| 外设 | ESP32 引脚 | 说明 |
|------|------------|------|
| 电位器模块 | GPIO 26 | ADC 输入（模拟） |
| 蜂鸣器 | GPIO 25 | LEDC PWM 输出，开发板自带 |
| 1位数码管模块(自带74HC595) | GPIO 23,18,5 | 共阳极接高电平 |
